## 实现方案：地址栏站点信息按钮 + 一键清理

### 一、新增 IPC 模块（后端）

**新建文件 `electron/ipc/site-data.ts`** — 导出 `registerSiteDataIpcHandlers()`，提供两个 handler：

1. **`siteData:getInfo`** 参数 `(tabId: string)` → 返回 `{ origin, hostname, cookieCount, storageBytes, quotaBytes, usageBytes }`
   - 通过 `webviewManager.getWebContents(tabId)` 拿到 webContents 和当前 URL
   - **cookieCount**：`wc.session.cookies.get({ url })` → `.length`
   - **storageBytes / usageBytes / quotaBytes**：`wc.executeJavaScript('navigator.storage.estimate()')` 拿 `usage`/`quota`；再执行一段脚本遍历 `localStorage` 累加 key+value 长度得到 `storageBytes`
   - 容错：tab 不存在、内部页面（`sessionbox://`）、executeJavaScript 失败时返回 0 / 空值，不抛错

2. **`siteData:clear`** 参数 `(tabId: string)` → 返回 `{ success: boolean }`
   - 解析当前 URL 得到 origin
   - 清当前域名 cookies：遍历 `session.cookies.get({ url })` 逐个 `session.cookies.remove(url, name)`
   - 调 `wc.session.clearStorageData({ origin })` 清 localStorage / IndexedDB / cache 等（Electron 的 `clearStorageData` 的 `origin` 选项会精确限定到该 origin）
   - `wc.session.cache` 无 origin 粒度，但 `clearStorageData` 的 `storages: ['serviceworkers','filesystem','indexdb','localstorage','shadercache','websql','cachestorage']` 配合 `origin` 已覆盖大部分场景
   - 成功后调用 `webviewManager.reload(tabId)` 自动刷新页面

**在 `electron/ipc/index.ts` 注册**：`registerIpcHandlers()` 末尾追加 `registerSiteDataIpcHandlers()` 调用，并在文件顶部 import。

### 二、Preload 桥接

**编辑 `preload/index.ts`** — 在 `api` 字面量中（`searchEngine` 附近）新增：

```ts
siteData: {
  getInfo: (tabId: string): Promise<SiteDataInfo> => ipcRenderer.invoke('siteData:getInfo', tabId),
  clear: (tabId: string): Promise<{ success: boolean }> => ipcRenderer.invoke('siteData:clear', tabId),
},
```

并 export 一个 `SiteDataInfo` 类型（在文件已有的 type 区域，或就近声明）：
```ts
interface SiteDataInfo {
  origin: string
  hostname: string
  cookieCount: number
  storageBytes: number
  usageBytes: number
  quotaBytes: number
}
```

### 三、新增组件 `SiteDataPopover.vue`

**新建 `src/components/toolbar/SiteDataPopover.vue`**（结构参照 `PasswordPopover.vue`）：
- 顶部标题：站点 hostname + Info 图标
- 信息区（每行：图标 + 标签 + 数值）：
  - Cookie 数量（`cookieCount` 个）
  - localStorage 大小（`formatBytes(storageBytes)`）
  - 总占用（`formatBytes(usageBytes)`，来自 storage.estimate，含 IndexedDB/Cache/SW）
  - 配额上限（`formatBytes(quotaBytes)`，可选展示）
  - 可选：进度条展示 `usage/quota` 占比
- 底部：**「一键清理」按钮**（Trash2 图标 + 确认）→ 调 `api.siteData.clear(activeTabId)` → 成功后 emit `cleared`，父组件可关闭 popover
- 内置 `formatBytes(bytes)`：`< 1024 → bytes + ' B'`，否则 `/1024` 带 KB/MB/GB 单位
- `onMounted` 时调 `loadInfo()`；内部页面/无 origin 时显示「请先打开一个网站」占位

### 四、集成到 `BrowserToolbar.vue`

在地址栏 Input 内部最右侧添加 Info 按钮（镜像左侧收藏 Star 按钮的绝对定位模式）：

1. 在 `<Input>` 外层 `relative` div 内、Input 之后，加一个 `<Popover>` 包裹的绝对定位按钮：
   ```
   <Popover v-model:open="siteDataPopoverOpen">
     <PopoverTrigger as-child>
       <Button absolute right-0.5 ... :disabled="!tabStore.activeTabId || isInternalPage">
         <Info class="w-3.5 h-3.5" />
       </Button>
     </PopoverTrigger>
     <PopoverContent class="w-80 p-0">
       <SiteDataPopover @cleared="siteDataPopoverOpen = false" />
     </PopoverContent>
   </Popover>
   ```
2. Input 增加 `pr-7` 让出右侧按钮空间（与现有 `pl-7` 对称）
3. import `Info` from lucide-vue-next；import `SiteDataPopover`
4. 新增 `const siteDataPopoverOpen = ref(false)` 与 `isInternalPage` computed（已有 `tabStore.activeTab?.url?.startsWith('sessionbox://')` 判断模式可复用）

### 六、边界处理

- **内部页面**（`sessionbox://`）：Info 按钮 disabled
- **冻结 tab / 无 webContents**：getInfo 返回 0，clear 返回 `{success:false}`，不崩溃
- **清理前确认**：用 `AlertDialog` 或简单的 `window.confirm`（保持轻量，倾向于直接执行 + toast 反馈，因为用户已通过 popover 明确意图；若你倾向二次确认可改用 AlertDialog）
- **清理后刷新**：clear handler 内部调 `webviewManager.reload(tabId)`，前端无需额外处理
- **多 tab 同容器**：只清当前域名，不影响其他网站数据

### 七、不做的事

- 不做容器级全量清理（已确认仅当前域名）
- 不做 service worker 单独管理 UI（包含在 clearStorageData 内）
- 不动 `electron/services/` 下其他文件（webviewManager 已有 `getWebContents`/`reload` 可直接复用）
