## 实现方案：手动粘贴 Cookie 导入

在现有 `SiteDataPopover.vue` 增加「从其他浏览器导入 Cookie」按钮，点击后展开一个 textarea，让用户粘贴从其他浏览器 DevTools / 扩展复制的 cookie 字符串，解析后应用到当前 sessionBox session。

### 一、后端新增 handler

**编辑 `electron/ipc/site-data.ts`** 新增 `siteData:importCookies(tabId, cookieText)`：

1. 取当前 tab webContents + URL，解析 origin / hostname（内部页面/无 webContents → `{success:false}`）
2. **解析 cookie 字符串**，兼容两种常见格式：
   - **标准 Cookie 头格式**：`name1=value1; name2=value2`（DevTools Network 复制、curl 格式）
   - **每行一条格式**：`name=value` 换行分隔（Cookie 编辑器扩展导出）
   - 跳过空行、`#` 注释行、不包含 `=` 的行
   - name/value 按第一个 `=` 分割（value 可包含 `=`）
   - trim 处理
   - 同名后者覆盖前者
3. 对每条 cookie 调 `wc.session.cookies.set({ url: origin, name, value, path: '/' })`
   - 不设 domain → Electron 自动按 origin 派生为 host-only cookie
   - 不设 httpOnly → 默认 false（页面 JS 可读，符合手动导入预期）
   - secure 跟随 origin（https → true）
4. 返回 `{ success: boolean; count: number; skipped: number }`（skipped = 解析失败的条目数）
5. 单条 set 失败用 try-catch 跳过，不中断整体

### 二、Preload 桥接

**编辑 `preload/index.ts`** 在 `siteData` 块加：
```ts
importCookies: (tabId: string, cookieText: string): Promise<{ success: boolean; count: number; skipped: number }> =>
  ipcRenderer.invoke('siteData:importCookies', tabId, cookieText),
```

### 三、前端 UI

**编辑 `src/components/toolbar/SiteDataPopover.vue`**：

1. 在「一键清理」按钮上方/下方加一个「从其他浏览器导入 Cookie」按钮（`ClipboardPaste` 图标）
2. 点击后切换到「导入模式」视图（`importMode = ref(false)`）：
   - `<textarea>` 输入框，placeholder 示例：`name=value; name2=value2`
   - 底部说明文字：「支持 `name=value; name2=value2` 格式，或每行一条。将应用到当前域名 {{ hostname }}」
   - 「取消」+「导入」两个按钮
3. 点击「导入」→ 调 `api.siteData.importCookies(activeTabId, text)`：
   - 成功：`toast.success(\`已导入 ${count} 条 Cookie\`)` → 退出导入模式 → `loadInfo()` 刷新 cookie 数 → emit `cleared`（触发 popover 关闭并刷新页面让网站识别新登录态）
   - 失败：`toast.error`
4. import `ClipboardPaste` from lucide-vue-next

| 文件 | 改动 |

| `electron/ipc/site-data.ts` | +`importCookies` handler + cookie 字符串解析函数 |

### 五、设计要点

- **不清空旧 cookie**：追加/覆盖同名，保留其他（更安全；用户想全清可用旁边的「一键清理」）
- **导入后自动刷新页面**：让网站立即识别新登录态（复用 `emit('cleared')` 触发父组件关闭 popover，主进程无需 reload——或可选在主进程 handler 末尾 reload，与 clear 一致）
- **无新依赖**：纯字符串 split/trim
- **容错**：空字符串、纯空白、无 `=` 行全部跳过并计入 `skipped`，不报错
